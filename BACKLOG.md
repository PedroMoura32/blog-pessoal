# Backlog do Radar

Ideias para depois. Nada aqui está implementado.

## Seção de agenda do dia

Mostrar na capa os compromissos do dia, para ler junto com as notícias de manhã.

**Regra de segurança:** a agenda nunca vai para este repositório. O GitHub Pages grátis exige repositório público, então qualquer compromisso gravado aqui ficaria visível para qualquer pessoa com o link.

Caminhos possíveis:

1. **Rápido:** embutir o Google Agenda (modo "Agenda") na página com o código de incorporação do próprio Google. Funciona quando a pessoa está logada no Google; pode falhar se o navegador bloquear cookies de terceiros. O visual é limitado.
2. **Melhor:** a própria página pede permissão de leitura ao Google Agenda no navegador (login do Google, escopo somente leitura) e desenha o dia com o visual do Radar. Os dados ficam só no navegador. Exige criar um projeto no Google Cloud uma vez, com a origem do site autorizada.

Decisão pendente: qual caminho, e se o repositório ficará público.
